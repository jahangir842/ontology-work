# HR ontology learning project

This repository is a workspace for **you to build an HR ontology in Protégé**. It does not contain a finished ontology or installation scripts.

Start with [the hands-on guide](docs/HR_ONTOLOGY_GUIDE.md). It explains what to model, why each choice matters, how to enter it in Protégé, and how to check your result.

Download Protégé Desktop from the [official Protégé software page](https://protege.stanford.edu/software/#desktop-protege). If you are using Ubuntu, follow the step-by-step [Protégé Ubuntu Installation Guide](docs/installation-protege.md) to set up desktop shortcuts and HiDPI display scaling.

## Which route should I take?

1. **Recommended:** Open Protégé's example Pizza ontology for 10–15 minutes to see what classes, properties, and individuals look like. Then create your own small HR ontology from a blank file. The example is for learning the interface; your HR model is the actual project.
2. **If your only requirement is to use an ontology in Protégé:** Opening, inspecting, and running a reasoner on the example is enough to practice the tool. It does not demonstrate that you can design an HR ontology.
3. **If you already have an HR ontology from a trusted source:** You can open and extend it, but first check its license, scope, definitions, and whether its terms fit your HR questions. Do not import a large model just because it exists.

Your first deliverable can be a file you save yourself as `hr-ontology.owl`. Keep notes about any changes you make to the guide's proposed model.
